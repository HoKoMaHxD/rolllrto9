# بوت ألعاب ديسكورد — SNOW GAMES

بوت رسمي بتوكن Bot واحد، فيه خمس ألعاب عربية، أزرار تفاعلية، متجر روليت، نقاط وفوزات محفوظة، وصور تلقائية بطابع بنفسجي وأبيض قريب من المراجع المرفقة.

لتحديث النسخة السابقة، انقل ملف `.env` ومجلد `data` إلى الإصدار الجديد أو وجّه `DATA_DIR` إلى نفس المجلد الدائم. أوقف العملية القديمة ثم شغّل الإصدار الجديد.

## التشغيل السريع

1. ثبّت **Node.js 24 LTS**، أو إصدار **22.13.0 فأحدث**. الإصدارات الأقدم لا توفر قاعدة البيانات المستخدمة.
2. افتح [Discord Developer Portal](https://discord.com/developers/applications)، أنشئ تطبيقًا ثم Bot، وانسخ توكن البوت.
3. من **Bot → Privileged Gateway Intents** فعّل **Message Content Intent** لقراءة أوامر `+r` وغيرها. لا يحتاج البوت Server Members Intent.
4. أضف البوت إلى سيرفرك عبر **OAuth2 → URL Generator**، بالنطاقين `bot` و`applications.commands` والصلاحيات: View Channels، Send Messages، Embed Links، Attach Files، Read Message History. للألعاب داخل الثريدات أضف Send Messages in Threads.
5. انسخ `.env.example` إلى `.env`، ثم ضع التوكن في `BOT_TOKEN`. ضع آيدي سيرفرك في `GUILD_ID` لتظهر أوامر `/` في السيرفر المحدد بسرعة. عند تركه فارغًا تُسجّل الأوامر عالميًا وقد تتأخر في الظهور.
6. افتح الطرفية داخل مجلد المشروع وشغّل بالترتيب:

```bash
npm ci
npm start
```

في الاستضافة: **Install / Build Command** هو `npm ci`، و**Start Command** هو `npm start`. يمكن وضع المتغيرات في لوحة الاستضافة بدل ملف `.env`.

### تحديث اسم وأفتار البوت

بعد `npm ci`، شغّل `npm run brand` مرة واحدة من المجلد الذي يحتوي على المشروع وملف `.env`، أو من بيئة الاستضافة التي فيها `BOT_TOKEN`. يضبط الأمر اسم حساب البوت إلى **SNOW GAMES** ويضع شعار الـS في أفتاره.

تجد صورة الأفتار الجاهزة للرفع اليدوي في `previews/snow-avatar.png` والشعار الشفاف في `assets/snow-logo.png`. إذا احتجت تعديل اسم التطبيق أو أيقونته أيضًا، غيّرها من صفحة تطبيقك في [Discord Developer Portal](https://discord.com/developers/applications).

البوت لا يحتاج موقعًا أو منفذ HTTP. شغّل عملية واحدة للمشروع؛ لا تشغّل نسختين من نفس التوكن بالتوازي.

## الأوامر

| الأمر | الوظيفة |
|---|---|
| `+r` | روليت عادي |
| `+h` | هايد |
| `+m` | ألغام |
| `+c` | كراسي |
| `-r` | روليت عكسي |
| `/اضافة نقاط الشخص:@عضو العدد:10` | إضافة نقاط — للإدارة |
| `/ازالة نقاط الشخص:@عضو العدد:5` | إزالة نقاط — للإدارة |
| `/نقاط` | نقاطك وفوزاتك وأغراضك؛ يمكنك اختيار شخص آخر |
| `/المتصدرين` | أعلى 10 لاعبين حسب الفوزات ثم النقاط |
| `+s` أو `+وقف` أو `/ايقاف` | إلغاء القيم الحالي في الروم لصاحب القيم أو الإدارة |
| `/العاب` أو `+help` أو `+مساعدة` | شرح الأوامر |

في ديسكورد اختر `/اضافة` ثم الأمر الفرعي `نقاط` ثم الشخص والعدد. لا يمكن أن يحتوي اسم أمر سلاش واحد على مسافة، لذلك هذا يعطي صيغة `/اضافة نقاط` المطلوبة. وينطبق ذلك على `/ازالة نقاط`.

صاحب أمر البداية لا يدخل تلقائيًا؛ يضغط «دخول» مثل باقي اللاعبين. لا يوجد أكثر من قيم نشط في نفس الروم، ويمكن تشغيل ألعاب مستقلة في رومات مختلفة.

## القواعد المطبقة

### مشتركة

- التسجيل **20 ثانية** مع دخول وخروج وعدّاد للمشاركين، من لاعبين إلى 50 لاعبًا افتراضيًا.
- بداية كل لعبة تعرض عدد المشتركين والوقت المتبقي حتى يبدأ القيم فوق الصورة وأزرار التسجيل الرمادية. يختفي الوقت عند إغلاق التسجيل.
- عند التسجيل يظهر تأكيد خاص مختصر «تم الدخول» أو «تم الخروج».
- الأرقام مخفية أثناء التسجيل. بعد البداية: الأول رقم 1 ثم الثاني 2 وهكذا. الخروج ثم العودة أثناء التسجيل ينقل اللاعب إلى آخر ترتيب الدخول. الأرقام تبقى ثابتة بعد بداية القيم.
- كل فوز يمنح **نقطة واحدة وفوزة واحدة**. رسالة الفوز نص عادي فيه كأس ومنشن الفائز وعبارة «فوز مستحق!»، وتحته صورة مرفقة تظهر فيها المجاميع والاسم والأفتار.
- يوجد فاصل **5 ثوانٍ** بين جولات الروليت والهايد والكراسي. إعلان الطرد يظهر بمنشن في الروم. ضغط زر الطرد أو الكشف عن مربع أو حجز كرسي أو اختيار لغم لا يرسل تأكيدًا خاصًا.
- الرصيد والفوزات والأغراض **خاصة بكل سيرفر**. استخدام نقاط المتجر يخفض الرصيد فقط؛ لا يخفض الفوزات.
- إذا خرج الجميع في نفس اللحظة، ينتهي القيم دون فائز ودون نقاط. إذا لم يكتمل لاعبان عند البداية، يلغى القيم دون نقاط.
- لا تتجدد مهلة الدور عند الضغط على كشف أو على زر غير صحيح. الأزرار القديمة لا تنفذ إجراء في الدور الجديد.

### الروليت `+r`

عند إغلاق التسجيل يرسل البوت «تم الانتهاء من تسجيل جميع اللاعبين» قبل أول دور إذا اكتمل الحد الأدنى للمشاركة. كل دور يبدأ بمنشن صاحب الدور فوق عجلة بنفسجية بإطار لامع. يظهر اسم كل لاعب متبقٍ في خانة، ويظهر أفتار صاحب الدور في الوسط مع سهم يشير إلى اسمه. تحت العجلة أزرار الطرد المرقّمة بترتيب التسجيل. لصاحب الدور **20 ثانية**، وبعد الاختيار تُقفل أزرار الدور السابق وتبقى صورته في الروم.

إعلان الطرد يذكر المطرود، ويميّز بين الطرد اليدوي والعشوائي. عند تفعيل المرتدة يذكر صاحبها ومن حاول طرده. عند تفعيل النووي يعلن طرد جميع اللاعبين مع منشن مستخدمه قبل بطاقة الفوز.

زر «طرد عشوائي» يختار خصمًا من المتبقين أثناء دورك، ويُعطّل إذا بقي **9 لاعبين أو أقل**. المرتدة تعمل على الطرد العشوائي واليدوي. زر «انسحاب» متاح أثناء الروليت العادي فقط.

المتجر يظهر أثناء التسجيل للروليت العادي فقط. يلزم دخول القيم للشراء. كل عملية تشتري نسخة واحدة، ويمكن امتلاك عدة نسخ حتى 99 من كل غرض. الأغراض تبقى محفوظة حتى استخدامها ولو انتهى القيم أو خرج اللاعب.

| الغرض | السعر | السلوك |
|---|---:|---|
| مرتدة | 2 | عند استهداف حاملها بطرد عادي، تُستهلك مرتدة واحدة ويخرج المهاجم. مرتدة المهاجم لا تعكس المرتدة مرة ثانية. لا تحمي من انتهاء المهلة أو الانسحاب أو النووي. |
| كشف | **1** | تشتريه في التسجيل وتستخدمه أثناء دورك من زر «كشف» بجانب «انسحاب». تظهر لك وحدك قائمة اللاعبين المتبقين الذين يملكون مرتدة في تلك اللحظة. يستهلك كشفًا واحدًا حتى لو لم يوجد حامل مرتدة. |
| قنبلة نووية | 10 | أثناء دورك يظهر زر «قنبلة نووية» بجانب الانسحاب والكشف إذا كنت تملكها. استخدامها يستهلك واحدة وينهي القيم بفوزك فورًا. |

### الهايد `+h`

بعد التسجيل، تظهر 25 خانة للاختباء خلال **20 ثانية**. اختيارك يصلك في رد خاص، ولا يتغير شكل المربع أمام الآخرين. يمكن مشاركة المربع ويمكن تغيير مكانك قبل انتهاء الاختباء. يبدأ الكشف مبكرًا إذا اختبأ الجميع. من لم يختبئ في المهلة يخرج.

يتوزع الدور عشوائيًا بين المتبقين لكشف خانة خلال **20 ثانية**. عند الكشف تتحول العين المشطوبة إلى عين مفتوحة على زر معطل. إذا كانت الخانة فارغة يعلن البوت رقمها في الروم. كل من اختبأ فيها يخرج، **بما فيهم صاحب الدور إذا كشف مخبأه**. ينتهي القيم عند بقاء لاعب واحد، أو بدون فائز إذا خرج آخر اللاعبين معًا. يحاول البوت تسجيل إيموجيي العين تلقائيًا عند التشغيل. يمكنك تخصيصهما باستعمال `HIDDEN_EMOJI_ID` و`REVEALED_EMOJI_ID`.

### الكراسي `+c`

كل جولة تبدأ برسالة «خلك جاهز!» وأزرار معطلة لمدة **5 ثوانٍ**، ثم تتغير نفس الرسالة إلى تعليمات الجولة. عدد الكراسي أقل بواحد من عدد المتبقين، ومهلة الحجز الافتراضية **3 ثوانٍ** بعد ظهور أزرار الحجز. إذا عندك قيمة قديمة في ملف `.env` أو لوحة الاستضافة، حدّثها إلى `CHAIR_SECONDS=3`.

- أخضر «احجز!»: لكل لاعب كرسي واحد. عند امتلاء الكراسي أو انتهاء المهلة، يخرج من لم يحجز.
- أحمر «لا تحجز!»: من يضغط يخرج. من ينتظر يتأهل. احتمال الجولة الحمراء 35%، ولا تتكرر جولتان حمراوان متتاليتان.
- تظهر نتيجة الطرد في رسالة منفصلة قبل تجهيز الجولة التالية.
- إذا لم يضغط أحد في جولة خضراء، يخسر الجميع ولا يعلن فائز.

### الألغام `+m`

بعد اختيار رقم آمن يظهر دور اللاعب الثاني مباشرة. بعد إعلان الانفجار أو انتهاء مهلة لاعب، تبدأ المواجهة التالية بعد **ثانية واحدة** إذا بقي أكثر من لاعب.

يختار البوت لاعبين عشوائيًا للمواجهة الأولى. اللوحة **3×3** وفيها لغم واحد ثابت حتى تنتهي المواجهة. كل اختيار آمن يظهر بعين خضراء، واختيار اللغم يظهر بقنبلة حمراء مع إعلان «بوم!» ومنشن اللاعب الذي انفجر. كل دور في رسالة جديدة. إذا بقي أكثر من لاعب يعلن البوت اسم المتأهل، ويبدأ بعدها مواجهة جديدة بينه وبين لاعب عشوائي. مهلة الاختيار **20 ثانية**.

### الروليت العكسي `-r`

كل دور في رسالة جديدة بصورة عجلة بأسماء المتبقين. البوت يختار لاعبًا عشوائيًا، يعرض اختياره لمدة **4 ثوانٍ** ثم يعلن طرده، حتى يبقى آخر لاعب.

## حفظ البيانات

قاعدة البيانات: `data/arena.sqlite` مع ملفات SQLite المرافقة أثناء التشغيل. تحفظ النقاط والفوزات والأغراض وسجل التعديلات. لا يُمنح نفس القيم مكافأة مرتين.

**اجعل `DATA_DIR` يشير إلى مجلد دائم في استضافتك.** حذف المجلد أو استخدام قرص مؤقت يفقد البيانات. لإجراء نسخة احتياطية بسيطة، أوقف البوت ثم انسخ مجلد `data` كاملًا. لا ترفع قاعدة بياناتك أو ملف `.env` إلى مستودع عام.

الأقيام الجارية لا تستكمل بعد إعادة التشغيل: تُعطّل أزرارها ويُرسل تنبيه بالإلغاء متى كان البوت يملك صلاحيات الروم. تبقى النقاط والفوزات والأغراض محفوظة. ما تم استهلاكه قبل إعادة التشغيل لا يُعاد تلقائيًا.

## الإعدادات

| المتغير | الافتراضي | الوظيفة |
|---|---|---|
| `BOT_TOKEN` | مطلوب | توكن البوت الرسمي |
| `GUILD_ID` | فارغ | سيرفر تسجيل أوامر السلاش؛ فارغ للتسجيل العالمي |
| `ADMIN_IDS` | فارغ | آيديات إدارية إضافية مفصولة بفواصل |
| `GAME_CHANNEL_IDS` | فارغ | رومات بدء الألعاب؛ فارغ لكل الرومات |
| `GAME_ROLE_ID` | فارغ | رتبة مسموح لها ببدء الألعاب؛ فارغ للجميع |
| `DATA_DIR` | `./data` | مجلد دائم لقاعدة البيانات |
| `MAX_PLAYERS` | 50 | من 2 إلى 50 |
| `LOBBY_SECONDS` | 20 | مدة التسجيل |
| `TURN_SECONDS` | 20 | مهلة اختيار الروليت والهايد والألغام |
| `HIDE_SECONDS` | 20 | مهلة الاختباء |
| `CHAIR_SECONDS` | 3 | مهلة جولة الكراسي |
| `REVERSE_SECONDS` | 4 | مدة عرض اختيار الروليت العكسي |

الإدارة تستطيع بدء الألعاب رغم قيود الرتبة والروم. أوامر إضافة وإزالة النقاط افتراضيًا ظاهرة لأصحاب Administrator فقط، مع تحقق آخر داخل الكود. إذا أضفت شخصًا غير إداري إلى `ADMIN_IDS`، اسمح له باستخدام هذين الأمرين أيضًا من إعدادات السيرفر → Integrations → البوت → Commands؛ المتغير وحده لا يغير واجهة صلاحيات ديسكورد.

عند وجود أكثر من 25 زرًا، تظهر بقية الأزرار في رسالة أخرى؛ هذه طريقة لدعم 50 لاعبًا ضمن حدود مكوّنات ديسكورد. أزرار الانسحاب والمتجر لا تستهلك مكانًا من لوحة الهايد.

## Docker اختياري

```bash
docker build -t snow-games .
docker run -d --name snow-games --restart unless-stopped --env-file .env -v arena-data:/app/data snow-games
```

## المعاينات والتحقق

```bash
npm test
npm run preview
```

المعاينات داخل `previews/`. صور الدخول والأدوار والفوز والأفتار ملفات PNG بخلفية شفافة. بطاقة الفائز التجريبية تستخدم حروفًا بدل الأفتار لعدم ارتباطها بحساب حقيقي. أثناء تشغيل البوت يستخدم أفتار عضو السيرفر، أو أفتار حسابه. إذا تعذر تحميل الصورة، تظهر الأحرف البديلة.

الاختبارات تشمل: القواعد الخمس، أسعار المتجر، المرتدة والكشف والنووي، المهل، الأزرار القديمة، الضغط المتزامن، عدم تكرار المكافأة، حفظ البيانات وإعادة تشغيلها، وحدود المكونات، بالإضافة إلى محاكاة **500 قيم**. تم تشغيلها محليًا؛ لم تُجرَ تجربة حية بتوكن ديسكورد ضمن هذا التسليم.

## الملفات

- `src/engine.js`: قواعد الألعاب.
- `src/manager.js`: إدارة الجلسات والمهل وتزامن الضغطات.
- `src/store.js`: حفظ النقاط والفوزات والمخزون.
- `src/views.js`: الرسائل والأزرار والمتجر.
- `src/art.js`: صور التسجيل والروليت والفائز.
- `src/index.js`: اتصال ديسكورد والصلاحيات والأوامر.
- `assets/`: الخلفية والخطوط مع تراخيصها.
- `test/`: الاختبارات والمحاكاة.

صور التسجيل وبطاقة الفوز تحمل اسم **SNOW GAMES** وشعار الـS المرفق. يرسم البوت بطاقة الفوز مع أفتار الفائز واسمه وإحصاءاته. واجهة الأزرار تستخدم مكوّنات ديسكورد الأصلية، لذلك قد يختلف حجمها ولونها قليلًا بحسب الجهاز والثيم.
