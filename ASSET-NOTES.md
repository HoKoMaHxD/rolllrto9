# Visual asset notes

The transparent ribbon layer `assets/ribbons.png` was edited with the built-in image-generation tool from the earlier purple and pearl-white artwork. It retains real PNG alpha between and around the ribbons. The project uses it in the lobby cards, winner card and reverse roulette roster.

Edit prompt: Preserve the existing glossy metallic purple and white ribbons and their wide composition. Remove the entire dark background to transparent alpha, including the center, bottom and gaps between ribbons. Keep antialiased edges and the original highlights, colors and proportions. Add no lettering or background.

The five lobby cards render the original game icons and the SNOW GAMES wordmark with the supplied transparent S logo (`assets/snow-logo.png`). The winner card and Discord profile avatar use the same logo. The regular roulette wheel is drawn in Canvas in a violet and silver palette, with one name per segment and the active player's Discord avatar at the center. The whole preview set is generated by `npm run preview`. Bundled fonts include their license notices under `assets/fonts/`.
